# 🗑️ Abfall Neuenburg am Rhein

Abfuhrtermine für alle Ortsteile von Neuenburg am Rhein – als mobile Web-App.

## Funktionen

- 📅 Nächste Abholtermine auf einen Blick
- 🗺️ Alle 4 Ortsteile: Stadt, Grißheim, Steinenstadt, Zienken
- 📆 Kalenderansicht mit Farbkodierung
- 🔍 Abfalltrennung – was gehört wohin?
- 🔔 Erinnerungsfunktion (Abend & Morgen)
- 🌙 Dark Mode

## Daten

Abfuhrtermine 2026, direkt aus den offiziellen ICS-Dateien des ALB Breisgau-Hochschwarzwald konvertiert.

## Ortsteile

| Zone | Ortsteil |
|------|----------|
| 1 | Stadt (Neuenburg Kernstadt) |
| 2 | Grißheim |
| 3 | Steinenstadt |
| 4 | Zienken |

## Lokale Entwicklung

```bash
npm install
npm start
```

## Deployment

Gehostet auf [Vercel](https://vercel.com). Bei jedem Push auf `main` wird automatisch neu gebaut.
